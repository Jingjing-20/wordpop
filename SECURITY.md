# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Word Pop ESL, please report it by emailing or opening a private security advisory on GitHub.

**Please do not report security vulnerabilities through public GitHub issues.**

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |

## Security Notes

- This is a client-side educational game with no backend
- No user data is collected or stored
- Uses Web Speech API and Web Audio API (browser-native)
- All game data is processed locally in the browser
